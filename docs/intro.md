# GaiaMod Documentation

[GaiaMod](https://gaiawindwave90.github.io/GaiaMod/) is a mod of PenguinMod with improved performance, dark mode, addons, and more. This is the place where its extra documentation goes.

Related projects:

 - [GaiaMod Packager](https://gaiamod-main.github.io/GaiaMod-Packager/)
 - [GaiaMod Extension Gallery](https://gaiawindwave90.github.io/gm-extensions/)

These pages are [open source](https://github.com/gaiawindwave90/GaiaMod-Docs). Contributions are welcome.
